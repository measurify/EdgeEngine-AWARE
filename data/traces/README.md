# Traces

Hourly weather / soil series replayed by `edgeengine_aware.traces` (see
`examples/trace_driven.ipynb`).

| file | what it is |
|---|---|
| `demo_liguria_2023_hourly.csv` | **Synthetic** stand-in generated by `tools/make_demo_trace.py` (seed 2023): astronomical clear-sky irradiance for 44.05 N / 8.21 E with persistent cloudiness, Markov wet/dry days with gamma rainfall, a top-soil water bucket with drainage, evapotranspiration and summer irrigation, seasonal/diurnal temperature. Not measured data; it exists so that the code, tests and notebook run offline. |
| `albenga_2023_hourly.csv` | *(not shipped)* real ERA5 / ERA5-Land reanalysis for Albenga (Liguria) — create it with `python tools/fetch_open_meteo.py` (Open-Meteo archive, CC BY 4.0). The notebook uses it automatically when present. |

## Format

```
# site=...                       provenance as "# key=value" lines
# utc_offset_h=1.0               timestamps are local *standard* time (no DST jumps)
# start_local=2023-01-01T00:00
# unit:shortwave_radiation=W/m²
# kind:shortwave_radiation=preceding_mean
...
time,shortwave_radiation,soil_moisture_0_to_7cm,temperature_2m,relative_humidity_2m,precipitation
2023-01-01T00:00,0,0.3129,4.19,73.3,0
2023-01-01T01:00,0,0.3128,3.95,74.9,0
```

* `time`: ISO-8601 local timestamp (or plain seconds); the loader re-bases it to seconds since
  the first local midnight.
* `kind`: `preceding_mean` (irradiance in W/m² averaged over, precipitation in mm summed over,
  the hour that *ends* at the timestamp — the convention of weather archives) or `instant`
  (state variables, linearly interpolated). Unknown columns default to `instant`.
* Soil moisture is volumetric (m³/m³); `TraceFieldEnvironment(field_capacity=0.40)` converts it
  to the simulator's "fraction of field capacity".

Your own logger data works with the same loader: any columns, any sampling interval (the
loader interpolates / integrates as needed); name the columns as above or pass the names to
the backends.
